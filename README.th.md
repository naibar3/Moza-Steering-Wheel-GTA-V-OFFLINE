# WheelPlugin (ภาษาไทย)

ปลั๊กอิน Script Hook V สำหรับ **GTA V (Legacy, โหมดเล่นคนเดียว)** ที่เพิ่มการรองรับพวงมาลัยเต็มรูปแบบและชั้นซิมูเลเตอร์เล็กๆ:
Force Feedback, แป้นเหยียบ, เกียร์ H พร้อมคลัตช์จริง, เกียร์ sequential แบบ paddle, เบรกมือ, ระบบน้ำมันพร้อมปั๊มและราคา,
แดชบอร์ดสไตล์นีออน และเมนูในเกมสไตล์กระจกพร้อม **ข้อความภาษาไทย** (ฝังฟอนต์ไว้ในตัว)
เขียนและทดสอบกับ **Moza R3** แต่เลือกพวงมาลัย DirectInput ที่รองรับ FFB ให้อัตโนมัติ

> ภาษาอังกฤษ: [README.md](README.md) · คู่มือฉบับสมบูรณ์: [docs/USER_GUIDE.th.md](docs/USER_GUIDE.th.md)

**ทดสอบกับ GTA V Legacy build 1.0.3889.0 (Steam) เท่านั้น** ปลั๊กอินอ่าน/แก้หน่วยความจำของเกมด้วย byte pattern
เมื่อเกมอัปเดต บางฟีเจอร์อาจใช้ไม่ได้จนกว่าจะอัปเดต pattern (ดู [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md))

> ⚠️ **ใช้ได้เฉพาะโหมด Story** ห้ามใช้ใน GTA Online และต้องเปิดเกมแบบไม่มี BattlEye (`-nobattleye`)
> ไม่เกี่ยวข้องกับ Rockstar Games, Take-Two, Alexander Blade หรือ Moza ใช้ด้วยความเสี่ยงของตัวเอง

## ฟีเจอร์

**พวงมาลัย**
- **เลี้ยว:** เขียนมุมเลี้ยวเข้ารถโดยตรง (ไม่มีช่วงตายแบบจอย) ใช้มุมที่คุณตั้ง เท่ากันทุกคัน
- **Force Feedback:** แรงรวม ความฝืด ความหน่วง แรงคืนตัวจากการหมุนของรถ centering แบบเลือกได้ สั่นตามเครื่อง/ถนน/หลุม/ชน/เกียร์ขบ/หน้าดื้อ
  ความฝืดและความหน่วงคำนวณเองในซอฟต์แวร์ ใช้ได้กับทุกอุปกรณ์ ทิศของแรง "บวก" **วัดอัตโนมัติ**
- **เกียร์แมนนวล:** เกียร์ H (สูงสุด 10 เกียร์ + R) คลัตช์ที่มีจุดกัด เครื่องดับ สตาร์ทแบบกดค้าง รถคลาน ลิมิตเตอร์รอบ รอบเครื่องตามล้อ
  **Sequential** แบบ paddle **เบรกมือ** analog/ปุ่ม เหยียบเบรกไม่ทำให้รถถอยหลัง

**ชั้นซิมูเลเตอร์** (ทุกส่วนมีสวิตช์ของตัวเอง ปิดแล้วไม่ทำงานเลย)
- **น้ำมัน:** ถังต่อคัน กินตามความเร็วและคันเร่ง น้ำมันหมดเครื่องดับ เติมที่ปั๊มด้วยการกดปุ่มค้าง
  **ราคาเป็นบาทต่อลิตรหักจากเงินสดโหมด Story** เงินหมดก็เติมได้เท่าที่มี
- **ปุ่มเดียว** แตะ = ดับเครื่อง กดค้าง = สตาร์ท
- **ไอคอนปั๊มบนแผนที่และมาร์คเกอร์ 3 มิติ** หาเองระหว่างขับและจำไว้
- **แดชบอร์ดนีออน:** ความเร็วแบบ 7 ส่วน (KMH/MPH) เลขเกียร์ใหญ่ แถบรอบเครื่องสีรุ้ง แคปซูลแป้นแบบกระจก และแคปซูลน้ำมัน
- **ภาษาไทยทุกที่:** เมนู HUD แผงเติมน้ำมัน ด้วยฟอนต์ TH Sarabun ที่ฝังไว้ ไม่ต้องติดตั้งอะไรในเครื่องผู้เล่น
- **บล็อกปุ่มของเกมได้ (ไม่บังคับ):** F1 / F2 / F3 / F5-F8 (Rockstar Editor สลับตัวละคร) เพื่อให้มอดอื่นใช้ปุ่มได้

**เมนู (F11):** ลากแถบเลื่อนด้วยเมาส์ พิมพ์ค่าได้ bind แกน/ปุ่ม/คีย์ด้วยการคลิกแล้วใช้ตัวควบคุมจริง เลือกอุปกรณ์แต่ละบทบาท สไตล์กระจกนีออน
บันทึกทันที **Telemetry:** เก็บข้อมูลย้อนหลัง 25 วินาทีเป็น CSV ไว้แนบรายงานบั๊ก

ทุกอย่างบนจอวาดโดยปลั๊กอินเองผ่านตัววาด Direct3D 11 เล็กๆ (ฟอนต์และกล่องของเกมเป็นแค่ตัวสำรอง)

## สิ่งที่ต้องมี

- GTA V Legacy (เวอร์ชันข้างบน) โหมด **Story** DirectX 11
- [Script Hook V](http://www.dev-c.com/gtav/scripthookv/) (`ScriptHookV.dll` และ `dinput8.dll`) ให้ตรงกับเวอร์ชันเกม
- พวงมาลัย DirectInput (Force Feedback ไม่บังคับ)

## ติดตั้ง (ผู้ใช้)

1. ติดตั้ง Script Hook V (ตามคู่มือของตัวมันเอง)
2. คัดลอก `WheelPlugin.asi` และ `WheelPlugin.ini` ไปวางใน **โฟลเดอร์เกม** (ที่เดียวกับ `GTA5.exe`)
   ไม่ใช่โฟลเดอร์ `mods` ของ OpenIV หรือรัน `install.bat` จากแพ็กที่แจก
3. เปิดเกมแบบไม่มี BattlEye (ใส่ `-nobattleye` ใน `commandline.txt` หรือใน Launch Options ของ Steam)
4. เข้าโหมด Story กด **F11** แล้ว bind พวงมาลัย แป้น และปุ่ม ขั้นตอนเปิดครั้งแรก เคล็ดลับ Pit House ทุกการตั้งค่า
   และการแก้ปัญหาอยู่ใน [คู่มือผู้ใช้](docs/USER_GUIDE.th.md)

ปุ่มเริ่มต้น (เปลี่ยนได้ในเมนู): `F11` เมนู · `F10` สลับ ออโต้ → ธรรมดา → ซีเควนเชียล · `F8` เครื่องยนต์ (แตะ = ดับ กดค้าง = สตาร์ท) ·
`J` กดค้างที่ปั๊มเพื่อเติมน้ำมัน

## สร้างจากซอร์ส

ต้องมี Visual Studio 2022/2025 หรือ Build Tools ที่ลง workload **C++ x64** และ Windows 10/11 SDK

1. ดาวน์โหลด **Script Hook V SDK** จาก <http://www.dev-c.com/gtav/scripthookv/> (ใบอนุญาตไม่ให้แจกต่อ จึงไม่ได้รวมไว้ในที่นี้)
   แล้ววาง `inc\` และ `lib\ScriptHookV.lib` ใน `sdk\` (ดู [sdk/README.md](sdk/README.md))
2. รัน `build.bat` ได้ `build\WheelPlugin.asi` (static runtime ไม่ต้องลงตัวเสริม)
3. `scripts\deploy.ps1 -Game "<โฟลเดอร์ GTA V>" [-Launch]` บิลด์และคัดลอกเข้าเกม (ไม่ยอมทำถ้าเกมเปิดอยู่)
4. `scripts\package.ps1` สร้างไฟล์ zip สำหรับแจกสองชุด (ชุดติดตั้งและชุดซอร์ส)

ไฟล์ซอร์ส (`src/`): `main.cpp` (ปลั๊กอิน: ค่าตั้ง DirectInput force feedback เกียร์ น้ำมัน เมนู) `thai.h` (ข้อความไทย ตัวเรนเดอร์ข้อความ/รูปทรงด้วย GDI+
และตัววาด Direct3D 11) `dash.h` (แดชบอร์ดนีออนและแผงเติมน้ำมัน) `menu_style.h` (ชิ้นส่วนเมนูแบบกระจก) `font_data.h` (ฟอนต์ที่ฝัง
ดู `src/FONT_NOTICE.txt`) ซอร์สเป็น UTF-8 (`/utf-8`)

## สถานะ

ฟีเจอร์พวงมาลัยหลักใช้ในเกมระหว่างพัฒนาแล้ว ระบบน้ำมัน ข้อความไทย ตัวเลขความเร็วนีออน และแผงเติมน้ำมันเห็นว่าทำงาน
ส่วนเมนูนีออน แถบรอบเครื่อง/แคปซูลแป้น ไอคอนและมาร์คเกอร์ปั๊ม การบล็อกปุ่ม และการหักเงินสดจริง บิลด์แล้วแต่ยังไม่ยืนยันในเกมตอนแพ็ก 1.1.0 ส่วนใหม่ใน 1.2.0: ฟิตเม้นรถ (ความกว้างล้อ ความสูง แคมเบอร์) เห็นทำงานกับรถไม่กี่คัน ส่วนตั้งค่ามุมกล้อง หน้าอุปกรณ์และปุ่มควบคุมแบบเลื่อน และไอคอนปั๊มรัศมี 100 ม. บิลด์แล้วแต่ยังไม่ยืนยันในเกม
(ตารางในคู่มือผู้ใช้ หัวข้อ 14)
